# Day and Night, Richer 3D: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 200-tick day and night that changes behaviour (sleep, hunting, folk going home, slower village work), drawn in 3D with the three.js Sky and Water add-ons and a richer terrain look, and in 2D as a night tint.

**Architecture:**
- `src/shared/daytime.ts` (done, 9b12bc7) gives the phase from the tick.
- The sim reads it for behaviour. Both renderers read `dayPhase(snapshot.tick)`, so there is no protocol or save change.
- Tasks 1–4 own disjoint files and run in parallel. Task 5 integrates and runs the single test pass.

**Tech Stack:** TypeScript 7 strict, three.js 0.186.1 (`three/examples/jsm/objects/Sky.js`, `Water.js`), PixiJS 8, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-30-day-night-design.md`. Read it all, including "Calls after the builder check", which overrides the earlier sections.

## Global Constraints

- **Phase API (`src/shared/daytime.ts`):**
  - `DAY_TICKS = 200`;
  - `dayPhase(tick)`, where 0 is midnight and tick 0 is phase 0.30;
  - `daySegment(phase)`: night 0.85–0.20, dawn 0.20–0.30, day 0.30–0.75, dusk 0.75–0.85;
  - `isNight(tick)`, `light01(phase)`, `ticksUntilPhase(tick, phase)`.
- **No save-format change:** `SCHEMA_VERSION` stays 7. No new decision rows, no new saved being fields.
- **The only intended determinism change** is in Task 1. Its new `GOLDEN_HASH` goes in `tests/unit/golden.test.ts`, and the old value 1357125849, the new value and the reason go in DECISIONS.md.
- **Budgets:** `render3d` ≤ 220 KB gzip (150.6 KB now); main ≤ 350 KB. If over, stop and report. Don't raise a cap.
- **Phones:** every new 3D cost has a degrade step and stays off the phone test's failure path.
- **Process:**
  - Agents commit on their own worktree branch with `Co-Authored-By: Claude Haiku 5.5 <noreply@anthropic.com>`. They don't merge or push.
  - Agents run only their own unit tests, both tsc configs, and the build plus budget check where noted.
  - No Playwright and no full suites: Task 5 runs those once.

## Review Focus

1. **An old save at night:** it loads mid-night, and every diurnal being goes to sleep within a few ticks rather than all at once with no flicker. Task 1 test `old save loads at night and diurnals fall asleep`.
2. **10× speed:** the drawn sky doesn't strobe, and phase smoothing never jumps more than 0.05 per frame. Task 2 test `smoothing caps the per-frame step`.
3. **A sea-less map:** the Water mirror isn't created, and a map with only lakes has no mirror pass. Task 3 test `no sea, no mirror`.
4. **Danger at night:** a sleeping diurnal being attacked at night still wakes and flees. Task 1 test `night sleeper wakes on damage`.
5. **The overview camera at noon:** the sky doesn't wash out the map, and terrain brightness stays within ±15% of before. Task 5 manual check plus screenshot.

- [ ] **Step 2:** Implement:

- [ ] **Step 3:** Run the tests and both tsc configs, plus `npm run build && npm run check:budgets`. Commit: `feat(render3d): sky, sun, moon and stars follow the day`.
